## 🧠 About This Repository

This repository contains my journey through **Data Structures and Algorithms using C++**.

The purpose of this repository is not simply to collect solved problems.

The focus is on understanding:

* 🧩 How to recognize a problem-solving pattern
* 🧠 How to break a problem into smaller parts
* ⚙️ How to convert an idea into an algorithm
* 💻 How to implement the solution cleanly in C++
* 📊 How to analyze time and space complexity
* 🎯 How to recognize the same pattern in a completely different problem
* 🔍 How to improve a brute-force solution into an optimized one

The problems are organized topic-wise so that each concept can be learned, practiced, revised, and reused.

# 🧩 Problem-Solving Framework

Every problem is approached using the following framework:

### 1️⃣ Understand

Read the problem carefully.

Identify:

* Input
* Output
* Constraints
* Important conditions
* Edge cases

### 2️⃣ Identify the Pattern

Ask:

> "Have I seen a similar structure before?"

Possible patterns:

```text
Hashing
Two Pointers
Sliding Window
Prefix Sum
Binary Search
Stack
Heap
BFS
DFS
Greedy
Backtracking
Dynamic Programming
```

### 3️⃣ Develop the Logic

Break the problem into simple steps.

### 4️⃣ Write the Algorithm

Convert the logic into a clear sequence of operations.

### 5️⃣ Implement

Write the solution in clean, readable C++.

### 6️⃣ Dry Run

Test the algorithm manually with a small example.

### 7️⃣ Analyze

Determine:

```text
Time Complexity
Space Complexity
```

### 8️⃣ Reflect

Ask:

> "What variation of this problem could appear in an interview?"

### Example

```text
LC 283 — Move Zeroes

Pattern:
Two Pointers

Logic:
Use one pointer to scan the array and another to track
the position where the next non-zero element should go.

Algorithm:
1. Traverse the array.
2. When a non-zero element is found, place it at the
   next available position.
3. Continue until the array is processed.

Complexity:
Time: O(n)
Space: O(1)
```
